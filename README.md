# CassettePlayer — первый прототип

Минимальный нативный macOS-плеер:
- перетаскивание аудиофайла;
- Play / Pause;
- Stop;
- отображение названия и времени;
- без кассеты, EQ и визуализатора — это будет следующим этапом.

## Запуск на Mac

1. Установи Xcode из Mac App Store, если он ещё не установлен.
2. Распакуй архив.
3. Открой файл `Package.swift` в Xcode.
4. Нажми Run (▶).
5. Откроется окно CassettePlayer.
6. Перетащи MP3 из Finder в пунктирную область.

Минимальная версия macOS: 13 Ventura.

Примечание: в первом прототипе ползунок времени пока только отображает прогресс; полноценный seek добавим после проверки базового воспроизведения.
